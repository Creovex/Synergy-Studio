# Intake: understand the job exactly, then lock it in brief.md

## 1. Read the request first
List what the request already answers. **Never ask an item it answers.** For every open item ask:
"would a different answer change the video?" If not, it is IMMATERIAL: don't ask, don't mention.

## 2. What must be known (the checklist)
| Item | Default if the user doesn't say (state it aloud, never ask it) |
|---|---|
| Kind of video (ad · explainer · footage edit · photo ad · story/film · art or music piece) | from what they gave you |
| Reference video or images: style, structure or both? | style; call `studio_reference_study` and write the style card (cinema.md §1); a look to copy: `studio_look_from` (styles.md) |
| Platform and format | 9:16 for social, 16:9 for YouTube/website |
| Length | 30 s social, 60–90 s explainer |
| **Audience**: one person in a situation, not a demographic | never defaulted: ask |
| **Single message**: one sentence, no "and" | never defaulted: ask or propose one for confirmation |
| Call to action: one verb, one object, where | plain sign-off with the brand name/handle |
| Offer / price / dates (exact) | none |
| Brand spelling, handle, website, logo file, colours | ask for files; never redraw a logo |
| Tone in 3–5 words, each with what it must not be ("direct, not curt") | from the brand's own posts if supplied |
| One thing it must never look or sound like | none |
| Voice (or the user's own recorded voice) and music | `af_heart` 0.95, generated `warm` music |
| **Is a real person on camera or named?** | never defaulted: ask; a real person's likeness needs their footage/photo |
| Facts and numbers (each with a source) | leave out anything unsourced |
| Variants (other formats, other hooks) | one finished version |
| Review checkpoint (plan first? stills first?) | show the plan for anything over 30 s; otherwise the finished cut once |
| Deadline | normal pace |
Compliance (ask as separate yes/no questions only when it applies): Is anyone paid or gifted to appear
(then a disclosure line is required)? Is it about politics or an election (then decline or follow the
platform's political-ad rules)?

## 3. How to ask
- Rank the open items by how much they change the video; ask the top ones, **at most 4 per message**,
  as numbered questions with lettered options, and add: "Answer with the letters or in your own words.
  Say 'you choose' for any."
- A second round only for items the first answers newly opened. Never re-ask a settled item.
- An unclear answer gets one narrow follow-up; then take the default and list it as an open gap.
- State every default you take in your message ("I'll assume one 30-second 9:16 version.").

## 4. Write brief.md (template made by `studio_project_new`)
One line per item marked `ANSWER:` (the user's words), `DEFAULT:` (your stated default), `PROPOSED:`
(your suggestion that needs the user's yes, e.g. a message you drafted) or `UNRESOLVED:` (with the reason,
also under Open gaps). If the user can't be reached (nobody can answer, for example a scheduled run), take the stated defaults, build with PROPOSED items and list them in the delivery
message as "assumed; tell me if any is wrong". Every later step reads brief.md; a fact that is
not in it is not invented later: go back and ask one targeted question.

## 5. The business frame (ads and explainers: five sentences, in brief.md, before any script)
For a story, film or art piece write instead: the feeling (start → end), the arc in 5–7 beats, the
characters and what each wants, and the style card. Build when those are clear.
| Field | Weak | Strong |
|---|---|---|
| Audience | "women 25–40" | "A Lagos professional choosing a signature scent for a first date." |
| Alternative | "competitors" | "She buys the same designer perfume everyone at work wears." |
| Single message | "Quality perfumes and great deals and fast delivery" | "HAURA helps you find a scent people remember you by." |
| Call to action | "Engage with us" | "DM @haura_scent today to order with 5% off." |
| Success | "More engagement" | "The owner watches it and says it looks like a premium brand, and the offer is clear by second 5." |
Audience or message still unknown → **do not build**; ask. Only "success" unknown → build and say so.
The whole video must agree with the frame: the message appears in words, the CTA is concrete, no second
tagline competes, the audience's situation is recognisable, and it answers their alternative.

## 6. Restate before building
Send a 4–6 line summary (message, audience, structure with timings, look, voice/music, CTA) and ask:
"a) Build it  b) Show me stills first  c) Change something".

## 7. Brand voice from samples (when the user gives posts, captions or a website)
Count, don't guess: typical sentence length (median) and the longest; words they repeat (use them);
words they never use (avoid them); how they address people (you/we); emoji and punctuation habits. Write
it into brief.md → "Brand and voice" and ask the user to confirm once. Reuse it on every video for them.
