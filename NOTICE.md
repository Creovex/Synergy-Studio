# NOTICE

Synergy Studio Lite does not bundle third party code. Its setup step downloads or builds the components below into the tool home (`~/Library/Application Support/SynergyStudioLite`) on the user's machine, and the MCP server runs them. This file lists each component, its licence, how this build uses it, and where its source is. Licences were read on 2026-09-30 from the installed copies first, and from the official web page only where the installed copy does not state the licence. Licence identifiers are quoted exactly as the source gives them. Anything not confirmed is marked UNCONFIRMED with what was checked. The development dependencies at the end are used for tests and packaging only and are not shipped in the bundle.

## Fonts

All four fonts are installed from `@fontsource/*` 5.3.0 packages, whose `package.json` says `OFL-1.1` and whose `LICENSE` files carry the SIL Open Font License, Version 1.1. The OFL lets the fonts be used, embedded in video, and redistributed, but they must not be sold on their own, must keep their copyright and licence text with any copy, and a modified font may not use its Reserved Font Name. This build uses the fonts unmodified as `.woff2` files copied into a project's `src/assets/fonts/` for rendering, and never sells them alone. Whether each font's `LICENSE` is copied next to the `.woff2` files in a project is UNCONFIRMED (the setup and compose code is not built yet); this file carries the copyright lines above in the meantime.
